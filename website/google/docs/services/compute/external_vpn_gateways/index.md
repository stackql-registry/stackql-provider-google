<Tabs
    defaultValue="get"
    values={[

<TabItem value="get">

Returns the specified externalVpnGateway. Get a list of available<br />externalVpnGateways by making a list() request.

```sql
SELECT
id,
name,
creationTimestamp,
description,
interfaces,
kind,
labelFingerprint,
labels,
params,
redundancyType,
selfLink
FROM google.compute.external_vpn_gateways
WHERE project = '{{ project }}' -- required
AND externalVpnGateway = '{{ externalVpnGateway }}' -- required
;
```
</TabItem>
